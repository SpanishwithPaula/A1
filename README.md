# Repaso de español · 19 unidades

App educativa de español con enfoque conversacional. Incluye 152 situaciones orales, 57 textos, 266 oraciones de práctica, traducciones al inglés y láminas integradas.

## Publicar con GitHub Pages

1. Crea o abre el repositorio donde quieres publicar la app.
2. Descomprime este ZIP en tu computador.
3. En el repositorio, selecciona **Add file → Upload files**.
4. Sube `index.html`, `.nojekyll` y `README.md` directamente a la raíz del repositorio. No subas el ZIP ni una carpeta que contenga estos archivos. Si tu computador oculta `.nojekyll`, los otros dos archivos bastan para esta app HTML.
5. Guarda con **Commit changes** en la rama `main`.
6. Abre **Settings → Pages**.
7. En **Build and deployment**, elige **Deploy from a branch**.
8. Selecciona la rama `main` y la carpeta **/(root)**, y pulsa **Save**.
9. Cuando termine la publicación, abre la dirección que muestra GitHub Pages.

Si el repositorio usa otra rama principal, selecciona esa rama en lugar de `main`.

La dirección habitual es `https://TU_USUARIO.github.io/NOMBRE_DEL_REPOSITORIO/`.

## Archivos

- `index.html`: aplicación completa, estilos, código, contenido e imágenes integradas.
- `.nojekyll`: indica que los archivos deben servirse directamente.
- `README.md`: estas instrucciones.

No requiere npm, servidor, claves, instalaciones ni proceso de compilación. Las imágenes están incluidas dentro del HTML y no dependen de rutas externas.

## Uso

Abre `index.html` directamente en un navegador o visita la dirección de GitHub Pages. El audio utiliza las voces disponibles en el navegador y puede depender del dispositivo y de la conexión. El progreso se guarda por navegador y dirección; para moverlo desde el HTML local al sitio publicado, usa **Guardar copia / Export** y luego **Cargar copia / Import**.
