# Español con Paula · Repaso A1

Sitio estático, sin instalación ni compilación.

## GitHub Pages
1. Descomprime este ZIP.
2. Sube index.html, la carpeta audio y los demás archivos a la raíz de tu repositorio.
3. En Settings > Pages elige Deploy from a branch, tu rama principal y / (root).
4. Abre la dirección de GitHub Pages cuando termine el despliegue.

## Contenido
21 unidades y un acceso a Vocabulario con 12 categorías y 1.200 entradas (100 por categoría).
Cada categoría incluye bloques, flashcards, lectura, práctica y preguntas personales.
Países y nacionalidades también ofrece un filtro por continente.
Las unidades independientes Adverbios y Posesión y posesivos incluyen cuadros, reglas,
12 oraciones, transformación de frases, 3 lecturas y 12 preguntas abiertas cada una.

## Respuestas
Se guardan en este navegador. El botón superior Guardar respuestas en PDF reúne las
respuestas de unidades y vocabulario. En el diálogo del navegador selecciona Guardar
como PDF. Usa Guardar copia / Cargar copia para trasladar el progreso a otro navegador.

## Audio y traducciones
Los botones España y Latam reproducen voz sintética neuronal incluida (Elvira y Dalia).
Conserva toda la carpeta audio. Pasa el cursor, enfoca o toca el texto subrayado para
ver la traducción al inglés. Los textos ya incluidos y sus fotografías se conservan.

El HTML independiente se entrega por separado con los audios integrados. Para GitHub
usa este ZIP: sus archivos de audio están separados para evitar un HTML demasiado grande.
